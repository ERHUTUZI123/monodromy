# Monodromy

**Topology-Native Computational Learning** · Independent research · November 2026

Monodromy investigates whether a learning system can use the topology of its own computational substrate to **construct, preserve, compose, and improve computational operations**.

The proposed architecture combines a learnable geometric substrate, a path generator, a continuous monodromy executor, a memory of reusable operations, and mechanisms for structural growth. Its long-term ambition is a general learning architecture in which new capabilities arise through learned geometric and topological organization.

## Primary research question

**Can topology-preserving geometric adaptation make future computational capabilities cheaper or easier to acquire?**

We study this with mathematically valid path lifting, task-driven acquisition of new operations, and comparisons against ordinary constraints, discrete search, and other strong baselines. All search, execution, training, storage, and verification costs count.

## Current status

Prior experiments demonstrate executable monodromy operations and preservation under safe deformations, but **have not established an independent learning-efficiency or resource advantage**. Productive geometric plasticity remains an open hypothesis.
